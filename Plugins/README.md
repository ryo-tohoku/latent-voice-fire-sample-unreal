# Plugins

Put the `LatentVoice` folder from the developer portal here, so that this file sits beside `LatentVoice/LatentVoice.uplugin`:

```
Plugins/
  README.md
  LatentVoice/
    LatentVoice.uplugin
```

Close the Editor first, then open `FireUnreal.uproject` again and choose **Yes** to rebuild. The plugin stays out of version control (`.gitignore`).

---

開発者ポータルから入手した `LatentVoice` フォルダーをここに置きます。このファイルと `LatentVoice/LatentVoice.uplugin` が並ぶ形です。先に Editor を閉じ、もう一度 `FireUnreal.uproject` を開いて **Yes** で再ビルドします。プラグインはバージョン管理に含めません（`.gitignore`）。
